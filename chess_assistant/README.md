# ♟ Chess Assistant (Stockfish + Vision + Stealth HUD)

Универсальный шахматный подсказчик для тестирования в **Discord («Chess in the Park»)** и демонстрации на **Chess.com**.

---

## 🚀 Быстрый старт

### 1. Калибровка (1 раз перед партией)
Откройте окно с шахматами (в Discord или браузере) и запустите:
```bash
cd chess_assistant
./run.sh calibrate
```
1. Наведите мышь на **верхний левый угол** шахматной доски (клетка a8) и нажмите **Enter**.
2. Наведите мышь на **нижний правый угол** доски (клетка h1) и нажмите **Enter**.
3. Выберите цвет (белые/черные).
4. Проверьте сохраненный тестовый снимок `test_calibrated_board.png`.

---

### 2. Запуск подсказчика
```bash
./run.sh
```

---

## 🥷 Скрытный режим (Stealth HUD)
Чтобы утилита **не была видна на стриме / демонстрации экрана**:
1. Откройте на телефоне (в той же Wi-Fi сети) ссылку, которую программа пишет при старте:  
   👉 `http://192.168.x.x:8765`
2. На экране телефона будут в реальном времени отображаться:
   * Доска с стрелкой лучшего хода
   * Оценка позиции (`+0.85` или мат в X ходов)
   * Краткое объяснение идеи хода
   * Альтернативные варианты

*Либо на компьютере транслируйте в Discord **только окно игры**, а не весь рабочий стол — тогда консоль и сторонние окна не попадут в стрим.*

---

## ⌨️ Команды во время игры (в терминале)
* **`Enter`** или **`h`** — запросить подсказку для текущей позиции.
* **`auto on`** / **`auto off`** — включить / выключить авто-сканирование экрана каждые 400мс.
* **`flip`** — сменить цвет (Белые ↔ Черные).
* **`sync`** — обновить опорный снимок доски (если случайно сдвинули окно).
* **`new`** / **`reset`** — начать новую партию с начальной расстановки.
* **`u`** — отменить последний ход.
* **`m e2e4`** — сделать ход вручную (если нужно синхронизировать).
* **`q`** — выход.
